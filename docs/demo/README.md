# Demo collateral — Textilcolor / deepaudit.ch

Materials for the client demo of the awareness-simulation platform.

- **TAPhish-Demo-Presentation.html** — self-contained web slide deck (8 slides).
  Open in any browser, no network needed. Navigate with ← → / spacebar / the
  bottom dots; press **F** for fullscreen.
- **TAPhish-Demo-Overview.pdf** — one-page-style printable overview with all
  clickable links (demo env, PRs #160–#163, 5-step demo script, K1/K3 OSINT
  references, wave schedule, pre-wave checklist).
- **generate-overview-pdf.php** — regenerates the PDF from the bundled TCPDF.
  Run `php docs/demo/generate-overview-pdf.php` (paths are relative to the repo).
