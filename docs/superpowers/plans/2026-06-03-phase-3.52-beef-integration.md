# Phase 3.52 — BeEF integration (read-mostly surface)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make an operator's existing BeEF server show up as a first-class capability inside TAPhish — hook injection wired into SiteCloner, hooked-browser dashboard inside MailCmpDashboard, audit-log entries for hook events — *without* TAPhish executing offensive modules, running BeEF locally, or letting hooks fire on out-of-scope visitors.

**Architecture:** Operator brings their own BeEF (BYO). TAPhish stores the BeEF base URL + REST API key encrypted at rest (Phase 3.27/3.38 envelope), exposes per-clone hook-inject toggle in SiteCloner, polls `/api/hooks` to render a read-only dashboard widget on MailCmpDashboard, and emits audit-log rows on hook events. Module execution stays in BeEF's own UI — TAPhish never POSTs to `/api/modules/{id}/{hook}`.

**Tech Stack:** PHP 8.1+ (mysqli), jQuery + Bootstrap, PHPUnit 10.5, existing AES-256-GCM envelope, BeEF REST API (HTTP + JSON).

## Threat model + non-goals

Read this section first. The whole rest of the plan assumes these constraints.

**Why this is sensitive.** BeEF is a browser exploitation framework. A hook on a phishing landing page is the most aggressive surface the platform exposes — it crosses from "credential capture" into "live browser sessions the operator can drive." The integration must keep that line obvious to the operator and impossible to cross accidentally.

**Non-goals (explicit YAGNI list).**

| Out of scope | Why |
|---|---|
| Bundling, downloading, installing, or starting a BeEF server | Separate operational concern. BYO keeps the trust boundary clean. |
| Module-execution UI inside TAPhish (`/api/modules/{id}/{hook}`) | Module execution stays in BeEF's own UI so the audit trail lives in BeEF, not split across two systems. |
| Auto-fire modules on hook | Operator-initiated only. No auto-pwn. |
| WebSocket subscription to BeEF events | Poll-based for v1 (30 s); WS is a future optimization. |
| Persisting hooked-browser detail beyond the cache TTL | The hook is ephemeral. We render what BeEF reports, we don't shadow-store it. |
| Hook-on-by-default for any clone | Per-clone, per-campaign opt-in. Default off. Always. |
| Cross-engagement hook reuse | Each engagement has its own scope_allowlist. Hooks outside that scope get a warning badge AND a `BEEF/warn` audit row. |

**Hard requirements (do not violate).**

1. BeEF API key MUST be encrypted at rest via the Phase 3.38 envelope. Plain storage is a rejected change.
2. Hook injection MUST be per-clone opt-in. Default off.
3. Hooked-browser dashboard MUST flag out-of-scope browsers (`engagement.scope_allowlist`-driven).
4. If the BeEF server is unreachable, the cloned landing page MUST still work — the hook tag is async + non-blocking, the dashboard widget degrades to "BeEF unavailable."
5. Hook events MUST be auditable. New `BEEF` classifier kind covers `BEEF/info` (hook seen in-scope), `BEEF/warn` (hook seen out-of-scope), `BEEF/error` (poll failed).
6. The settings page MUST surface anti-malware caveat copy: SmartScreen, Sophos, Symantec, and a few EDR vendors signature-detect the BeEF hook. Operator needs to know the landing page burns faster with the hook on.

**Why a new `tb_data_clone_meta` table instead of a sidecar `meta.json`?** Three reasons: (1) we already do every other per-entity metadata in MySQL; sidecar JSON in `sniperhost/cloned/` would split state across two backing stores. (2) Audit-log + dashboard queries join naturally against MySQL. (3) The table also gives us a future home for clone-level engagement linkage (Phase 3.45b extended). The boot-time migration is idempotent, mirrors the Phase 3.45a pattern.

<?php
// spear/manager/beef_integration.php

if (!function_exists('beef_hook_snippet')) {
    function beef_hook_snippet(string $baseUrl, string $hookFile = 'hook.js'): string
    {
        $baseUrl = trim($baseUrl);
        if ($baseUrl === '' || !preg_match('#^https?://#i', $baseUrl)) return '';
        $url = rtrim($baseUrl, '/') . '/' . ltrim($hookFile, '/');
        $u = htmlspecialchars($url, ENT_QUOTES, 'UTF-8');
        return '<script async src="' . $u . '"></script>';
    }
}

if (!function_exists('beef_parse_auth_response')) {
    function beef_parse_auth_response($raw): ?string
    {
        $j = is_string($raw) ? json_decode($raw, true) : $raw;
        if (!is_array($j) || empty($j['success']) || empty($j['token'])) return null;
        return (string) $j['token'];
    }
}

if (!function_exists('beef_summarize_hooks')) {
    function beef_summarize_hooks(array $raw): array
    {
        $online = $raw['hooked-browsers']['online'] ?? [];
        if (!is_array($online)) return [];
        $out = [];
        foreach ($online as $id => $b) {
            if (!is_array($b)) continue;
            $browser = trim((string)($b['browser'] ?? ''));
            $ver = trim((string)($b['browser.version'] ?? ''));
            $out[] = [
                'id'      => (string) $id,
                'ip'      => (string) ($b['ip'] ?? ''),
                'domain'  => (string) ($b['domain'] ?? ''),
                'os'      => (string) ($b['os'] ?? ''),
                'browser' => $ver !== '' ? trim("$browser $ver") : $browser,
            ];
        }
        return $out;
    }
}

if (!function_exists('beef_validate_browser_in_scope')) {
    function beef_validate_browser_in_scope(array $browser, array $scopeAllowlist): array
    {
        $domain = strtolower(trim((string)($browser['domain'] ?? '')));
        if ($domain === '') return ['in_scope' => false, 'reason' => 'no domain'];
        foreach ($scopeAllowlist as $allowed) {
            $a = strtolower(trim((string) $allowed));
            if ($a === '') continue;
            if ($domain === $a || str_ends_with($domain, '.' . $a)) {
                return ['in_scope' => true, 'reason' => ''];
            }
        }
        return ['in_scope' => false, 'reason' => 'domain not in scope'];
    }
}

if (!function_exists('beef_list_hooked_browsers')) {
    function beef_list_hooked_browsers(string $baseUrl, string $token, ?callable $http = null): array
    {
        $url = rtrim($baseUrl, '/') . '/api/hooks?token=' . rawurlencode($token);
        $fn  = $http ?? 'beef_default_http';
        $resp = $fn('GET', $url, ['timeout' => 5]);
        if ((int)($resp['status'] ?? 0) !== 200) {
            return ['ok' => false, 'err' => 'HTTP ' . ($resp['status'] ?? 'unknown')];
        }
        $j = json_decode((string)($resp['body'] ?? ''), true);
        if (!is_array($j)) return ['ok' => false, 'err' => 'non-JSON response'];
        return ['ok' => true, 'hooks' => beef_summarize_hooks($j)];
    }
}

if (!function_exists('beef_default_http')) {
    function beef_default_http(string $method, string $url, array $opts = []): array
    {
        $ch = curl_init($url);
        curl_setopt_array($ch, [
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_CUSTOMREQUEST  => $method,
            CURLOPT_TIMEOUT        => $opts['timeout'] ?? 5,
            CURLOPT_CONNECTTIMEOUT => 3,
            CURLOPT_SSL_VERIFYPEER => true,
            CURLOPT_SSL_VERIFYHOST => 2,
        ]);
        $body = curl_exec($ch);
        $status = (int) curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        return ['status' => $status, 'body' => (string) $body];
    }
}

function taphish_clone_meta_ensure_schema(\mysqli $conn): void
{
    $stmt = $conn->prepare(
        "SELECT COUNT(*) FROM information_schema.TABLES
          WHERE TABLE_SCHEMA = DATABASE() AND TABLE_NAME = 'tb_data_clone_meta'"
    );
    if ($stmt === false) return;
    $stmt->execute();
    $row = $stmt->get_result()->fetch_row();
    $stmt->close();
    if ($row && (int)$row[0] > 0) return;
    @$conn->query(
        "CREATE TABLE tb_data_clone_meta (
            slug                VARCHAR(160) NOT NULL PRIMARY KEY,
            beef_hook_enabled   TINYINT(1) NOT NULL DEFAULT 0,
            engagement_id       INT NULL,
            created_at          BIGINT NOT NULL,
            updated_at          BIGINT NOT NULL,
            KEY (engagement_id)
         ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4"
    );
}

## Open questions to resolve at implementation start

1. **Hook file name** — BeEF defaults to `hook.js`, but operators commonly rename to evade signature detection. Task 3's settings page should accept an optional override (default `hook.js`).
2. **Per-engagement vs per-clone toggle granularity** — current plan is per-clone. Alternative: per-engagement (every clone in the engagement either has the hook or doesn't). Per-clone is more flexible but adds one form field; per-engagement is fewer clicks but less granular. **Recommendation: per-clone** (matches the existing per-clone `slug` model and lets the operator A/B which clones get the hook).
3. **Polling cadence** — 30 s for v1. Faster (10 s) means the operator sees hooks land near-instantly but burns more BeEF API quota. **Recommendation: 30 s with a "Refresh now" button.**
4. **Scope check on `domain` vs `referer`** — BeEF reports `domain` (URL the hook fired on). `domain` is what we have. If a hook fires on `evil.com` because the operator misconfigured the clone, we want to know — so checking `domain` against `scope_allowlist` catches that. **Decision: domain.**

- This plan does NOT make TAPhish capable of running BeEF modules. Module execution stays in BeEF's own UI. If the user later asks for module execution from TAPhish, that's a separate Phase 3.53 with its own threat-model conversation.
- The plan assumes BeEF runs on a host the operator controls (BYO). If a future ask is "TAPhish should bundle BeEF in the deploy artifact," that's a deployment plan change, not an integration plan change, and is also out of scope here.
- If the user wants Metasploit / SET-toolkit integration after this lands, the same shape applies: TAPhish is a *surface* for the operator's existing instance, never the execution layer. Each one is its own phase.
