# Phase 3.48b — Per-engagement PII isolation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scope recipient user-group visibility/access to the engagements an operator belongs to (super-admin sees all), closing RBAC requirement #4.

**Architecture:** Add a nullable `engagement_id` column to `tb_core_mailcamp_user_group` (idempotent boot migration + one-time backfill from campaign references). Pure helpers decide visibility; list reads add a `WHERE`, single-row ops call a forbidden-or-die guard, creation stamps the engagement. Cron sending stays unscoped. Encryption is untouched.

**Tech Stack:** PHP 8.1+ (mysqli), PHPUnit 10.5. Mirrors Phase 3.45b (campaign FK) + Phase 3.48 (authz) patterns.

Spec: `docs/superpowers/specs/2026-06-04-phase-3.48b-pii-isolation-design.md`.

// Pure: may a user with this global role + engagement memberships see/act on a
// user-group with this engagement_id? NULL engagement_id = legacy/unscoped =
// visible to any non-disabled operator (decision #1, no lockout).
function taphish_user_group_visible(?int $groupEngagementId, string $role, array $memberIds): bool
{
    if ($role === 'disabled') return false;
    if ($role === 'super-admin') return true;
    if ($groupEngagementId === null) return true;
    return in_array((int) $groupEngagementId, array_map('intval', $memberIds), true);
}

// Engagement ids the user belongs to (tb_core_engagement_member ⋈ tb_main).
function taphish_user_engagement_ids(\mysqli $conn, string $username): array
{
    if (!($conn instanceof \mysqli) || $username === '') return [];
    $stmt = $conn->prepare(
        "SELECT m.engagement_id FROM tb_core_engagement_member m
         JOIN tb_main u ON u.id = m.user_id WHERE u.username = ?"
    );
    if ($stmt === false) return [];
    $stmt->bind_param('s', $username);
    $stmt->execute();
    $res = $stmt->get_result();
    $ids = [];
    while ($r = $res->fetch_assoc()) { $ids[] = (int) $r['engagement_id']; }
    $stmt->close();
    return $ids;
}

// Dispatcher guard for single-row user-group ops: resolve the group's
// engagement_id, apply taphish_user_group_visible; deny → 403 +
// {result:'forbidden'} + audit log + exit (same shape as the action guard).
function taphish_user_group_guard_or_die(\mysqli $conn, string $group_id): void
{
    $username = (string) ($_SESSION['username'] ?? '');
    $role = taphish_user_role($conn, $username);
    $eid = null;
    if ($conn instanceof \mysqli && $group_id !== '') {
        $stmt = $conn->prepare("SELECT engagement_id FROM tb_core_mailcamp_user_group WHERE user_group_id = ?");
        if ($stmt !== false) {
            $stmt->bind_param('s', $group_id);
            $stmt->execute();
            $row = $stmt->get_result()->fetch_assoc();
            $stmt->close();
            $eid = isset($row['engagement_id']) && $row['engagement_id'] !== null ? (int) $row['engagement_id'] : null;
        }
    }
    if (taphish_user_group_visible($eid, $role, taphish_user_engagement_ids($conn, $username))) {
        return;
    }
    if (function_exists('logIt')) { logIt('Forbidden user-group ' . $group_id . ' attempted by ' . $username); }
    http_response_code(403);
    echo json_encode(['result' => 'forbidden', 'error' => 'You do not have access to this recipient list.']);
    exit;
}
```

// Pure: given the engagement_ids of every campaign referencing a user-group,
// return the single engagement to stamp it with, or null if zero / ambiguous.
function taphish_user_group_backfill_engagement(array $campaignRefs): ?int
{
    $ids = [];
    foreach ($campaignRefs as $r) {
        $eid = $r['engagement_id'] ?? null;
        if ($eid !== null && (int) $eid > 0) { $ids[(int) $eid] = true; }
    }
    return count($ids) === 1 ? (int) array_key_first($ids) : null;
}
```
